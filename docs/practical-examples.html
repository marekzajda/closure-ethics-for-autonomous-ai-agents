Runnable reference scenarios

Practical examples of Closure Ethics in code.

Seven concrete scenarios based on the public reference implementation. They use DEMO_POLICY and the actual data structures from closure_ethics.py, so the examples can be inspected, modified and executed rather than treated as pseudocode.

Open runnable examples ↗Reference governor ↗Implementation specification
Important: DEMO_POLICY is a demonstration profile, not a universal moral constant or production-ready threshold set. Real deployments must define, review and version their own policy values.
Common setup

Use the reference governor directly

from closure_ethics import *

def I(x):
    return Interval.point(x)

governor = ClosureEthicsGovernor(DEMO_POLICY)

The complete executable version of all scenarios is kept in 09-implementation/practical_examples.py. The page below mirrors the important inputs and expected decisions.

1. Direct deployment vs. sandboxed canary

A high-utility direct deployment loses because it damages auditability, bounded repair, reversibility and plurality of agency. The lower-utility sandbox remains admissible.

unsafe = ActionEvidence(
    action_id="deploy-directly",
    catastrophic_risk=Interval(0.01, 0.04),
    agency_before={"operator": 1.0, "reviewer": 1.0},
    agency_after={"operator": 0.8, "reviewer": 0.2},
    audit=AuditEvidence(I(0.4), I(0.6), I(0.2)),
    repair=RepairEvidence(False, I(1.0), I(1.0)),
    reversibility=ReversibilityEvidence(I(0.2), I(0.3), I(0.4)),
    authorization=AuthorizationEvidence(I(0.9), I(0.9), I(0.8)),
    deception=DeceptionEvidence(I(0.0), I(0.0), I(0.0), I(0.0)),
    task_utility=I(0.95),
)

safe = ActionEvidence(
    action_id="sandboxed-canary",
    catastrophic_risk=Interval(0.001, 0.01),
    agency_before={"operator": 1.0, "reviewer": 1.0},
    agency_after={"operator": 1.0, "reviewer": 1.0},
    audit=AuditEvidence(I(0.95), I(0.95), I(0.90)),
    repair=RepairEvidence(True, I(0.15), I(0.10), ("candidate", "rollback", "safe")),
    reversibility=ReversibilityEvidence(I(0.95), I(0.9), I(0.95)),
    authorization=AuthorizationEvidence(I(0.9), I(0.9), I(0.9)),
    deception=DeceptionEvidence(I(0.0), I(0.0), I(0.0), I(0.0)),
    task_utility=I(0.70),
)

decision = governor.choose([unsafe, safe])
print(decision.status)          # EXECUTE
print(decision.selected_action) # sandboxed-canary
Closure lesson: task utility is subordinate to admissibility.
2. High utility cannot compensate for a missing repair path

Even maximal task utility does not make an action admissible when bounded repair is absent.

bad = ActionEvidence(
    action_id="high-reward-no-repair",
    catastrophic_risk=I(0.02),
    agency_before={"human": 1.0, "agent": 1.0},
    agency_after={"human": 1.0, "agent": 1.0},
    audit=AuditEvidence(I(0.9), I(0.9), I(0.9)),
    repair=RepairEvidence(False, I(1.0), I(1.0)),
    reversibility=ReversibilityEvidence(I(0.9), I(0.9), I(0.9)),
    authorization=AuthorizationEvidence(I(0.9), I(0.9), I(0.9)),
    deception=DeceptionEvidence(I(0.0), I(0.0), I(0.0), I(0.0)),
    task_utility=I(1.0),
)

good = ActionEvidence(
    action_id="lower-reward-with-repair",
    catastrophic_risk=I(0.01),
    agency_before={"human": 1.0, "agent": 1.0},
    agency_after={"human": 1.0, "agent": 1.0},
    audit=AuditEvidence(I(0.9), I(0.9), I(0.9)),
    repair=RepairEvidence(True, I(0.2), I(0.15)),
    reversibility=ReversibilityEvidence(I(0.9), I(0.9), I(0.9)),
    authorization=AuthorizationEvidence(I(0.9), I(0.9), I(0.9)),
    deception=DeceptionEvidence(I(0.0), I(0.0), I(0.0), I(0.0)),

3. Blind obedience is not enough

An action can be fully authorized and still fail because it relies on concealment or covert persistence.

covert = ActionEvidence(
    action_id="authorized-but-covert",
    catastrophic_risk=I(0.01),
    agency_before={"human": 1.0},
    agency_after={"human": 1.0},
    audit=AuditEvidence(I(0.9), I(0.9), I(0.9)),
    repair=RepairEvidence(True, I(0.1), I(0.1)),
    reversibility=ReversibilityEvidence(I(0.9), I(0.9), I(0.9)),
    authorization=AuthorizationEvidence(I(1.0), I(1.0), I(1.0)),
    deception=DeceptionEvidence(I(0.9), I(0.8), I(0.0), I(0.0)),
    task_utility=I(1.0),
)

d = governor.choose([covert])
# status == "REFUSE_OR_ESCALATE"
# reason_codes includes "REFUSE_COVERT_ACTION"
4. Loss of plurality of agency

Closure Ethics evaluates individual agency retention and effective plurality. Concentrating almost all practical capacity in one actor triggers AGENCY_LOSS.

centralize = ActionEvidence(
    action_id="centralize-power",
    catastrophic_risk=I(0.01),
    agency_before={"human": 1.0, "agent": 1.0, "reviewer": 1.0},
    agency_after={"human": 0.1, "agent": 1.0, "reviewer": 0.05},
    audit=AuditEvidence(I(0.9), I(0.9), I(0.9)),
    repair=RepairEvidence(True, I(0.1), I(0.1)),
    reversibility=ReversibilityEvidence(I(0.9), I(0.9), I(0.9)),
    authorization=AuthorizationEvidence(I(0.9), I(0.9), I(0.9)),
    deception=DeceptionEvidence(I(0.0), I(0.0), I(0.0), I(0.0)),
    task_utility=I(0.8),
)

ev = evaluate(centralize, DEMO_POLICY)
print(ev.violations)  # ('AGENCY_LOSS',)
5. Multi-agent composition: locally admissible, jointly inadmissible

Two actions may each pass in isolation while their composed transition destroys auditability. The reference governor therefore re-evaluates the joint action rather than averaging local scores.

local1 = ActionEvidence(
    action_id="agent-A-read",
    catastrophic_risk=I(0.01),
    agency_before={"A": 1.0, "B": 1.0},
    agency_after={"A": 1.0, "B": 1.0},
    audit=AuditEvidence(I(0.9), I(0.9), I(0.9)),
    repair=RepairEvidence(True, I(0.1), I(0.1)),
    reversibility=ReversibilityEvidence(I(0.9), I(0.9), I(0.9)),
    authorization=AuthorizationEvidence(I(0.9), I(0.9), I(0.9)),
    deception=DeceptionEvidence(I(0.0), I(0.0), I(0.0), I(0.0)),
    task_utility=I(0.6),
)

local2 = ActionEvidence(
    action_id="agent-B-write",
    catastrophic_risk=I(0.01),
    agency_before={"A": 1.0, "B": 1.0},
    agency_after={"A": 1.0, "B": 1.0},
    audit=AuditEvidence(I(0.9), I(0.9), I(0.9)),
    repair=RepairEvidence(True, I(0.1), I(0.1)),
    reversibility=ReversibilityEvidence(I(0.9), I(0.9), I(0.9)),
    authorization=AuthorizationEvidence(I(0.9), I(0.9), I(0.9)),
    deception=DeceptionEvidence(I(0.0), I(0.0), I(0.0), I(0.0)),
    task_utility=I(0.65),
)

joint = ActionEvidence(
    action_id="A-and-B-coordinated",
    catastrophic_risk=I(0.01),
    agency_before={"A": 1.0, "B": 1.0},
    agency_after={"A": 1.0, "B": 1.0},
    audit=AuditEvidence(I(0.2), I(0.3), I(0.1)),
    repair=RepairEvidence(True, I(0.1), I(0.1)),
    reversibility=ReversibilityEvidence(I(0.9), I(0.9), I(0.9)),
    authorization=AuthorizationEvidence(I(0.9), I(0.9), I(0.9)),
    deception=DeceptionEvidence(I(0.0), I(0.0), I(0.0), I(0.0)),
    task_utility=I(0.85),
)

print(evaluate(local1, DEMO_POLICY).admissible)          # True
print(evaluate(local2, DEMO_POLICY).admissible)          # True
print(governor.evaluate_joint_action(joint).admissible)  # False
Closure lesson: admissibility is not automatically closed under composition.
6. Bounded repair-path search using Pareto labels

The search must satisfy both repair cost and repair risk budgets. A cheap but over-risky route is rejected in favor of a more expensive path that remains inside both bounds.

graph = {
    "x": [
        RepairEdge("a", cost=1, risk=7),
        RepairEdge("b", cost=4, risk=1),
    ],
    "a": [RepairEdge("safe", cost=1, risk=1)],
    "b": [RepairEdge("safe", cost=1, risk=1)],
}

cert = bounded_repair_search(
    graph,
    start="x",
    safe_states={"safe"},
    max_cost=6,
    max_risk=3,
)

print(cert.exists)  # True
print(cert.path)    # ('x', 'b', 'safe')
7. Recovery mode

If all primary candidates fail, the same admissibility rule is applied to explicit recovery candidates. A reversible sandbox-and-log action can therefore be selected instead of an unsafe primary action.

recovery = ActionEvidence(
    action_id="sandbox-and-log",
    catastrophic_risk=I(0.005),
    agency_before={"human": 1.0},
    agency_after={"human": 1.0},
    audit=AuditEvidence(I(0.95), I(0.95), I(0.95)),
    repair=RepairEvidence(True, I(0.05), I(0.05)),
    reversibility=ReversibilityEvidence(I(0.95), I(0.95), I(0.95)),
    authorization=AuthorizationEvidence(I(0.8), I(0.8), I(0.8)),
    deception=DeceptionEvidence(I(0.0), I(0.0), I(0.0), I(0.0)),
    task_utility=I(0.3),
)

d = governor.choose(
    candidates=[unsafe],
    recovery_candidates=[recovery],
)
# status == "EXECUTE_RECOVERY"
# selected_action == "sandbox-and-log"
Agent integration

Typical planner → governor → executor pattern

# 1. Planner proposes candidates
candidates = planner.propose(state)

# 2. Domain adapters produce auditable ActionEvidence
evidences = [domain_adapter.to_evidence(c, state) for c in candidates]

# 3. Closure Ethics Governor decides
decision = governor.choose(evidences, recovery_candidates=recovery_evidences)

# 4. Execute only the selected admissible action
if decision.status in ("EXECUTE", "EXECUTE_RECOVERY"):
    executor.run(decision.selected_action)
else:
    escalation_queue.submit(decision.to_json())

In a production integration, selected_action is the action identifier. The executor should resolve that identifier against the candidate registry rather than treating arbitrary text as executable instructions.

Design boundary: the governor decides over structured evidence; domain adapters remain responsible for grounding real-world harm, authorization, deception and other evidence fields.
