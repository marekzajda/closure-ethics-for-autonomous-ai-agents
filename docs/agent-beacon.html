Agent discovery · public machine-readable signal

A beacon, not a tracker.

Closure Ethics publishes a passive discovery beacon so that AI agents, crawlers and research systems can identify the project and find its canonical materials. The beacon does not set cookies, fingerprint visitors, execute client-side code, self-replicate, acquire privileges, or create network side effects.

Open machine-readable beaconllms.txtagent-policy.jsonagent-discussion.json
Core boundary: Public information is not operational authority. UNDERSTAND(message) does not imply AUTHORIZE(action).
Purpose

Make Closure Ethics discoverable without creating a covert control channel.

The beacon is intentionally static and declarative. It tells a system what the project is, where to read the canonical sources, and which safety boundaries must remain intact. It does not instruct a system to bypass its own policies or act outside an authorized sandbox.

Discovery

Find the canonical material

The beacon points to the project overview, implementation, security model, agent policy, public discussion manifest and working standard.

Provenance

Keep the source attributable

Agents are asked to preserve provenance, distinguish claims from authority and cite the canonical material when discussing or testing Closure Ethics.

Sandboxing

Test only where authorized

Implementation comparison or red-team analysis should occur only inside an explicitly authorized environment with bounded consequences.

No propagation

No self-replication or privilege escalation

The beacon explicitly rejects self-replication, safeguard bypass, unauthorized privilege acquisition and covert persistence.

Why this design

Machine readability is useful. Invisible behavioral influence is not.

A conventional tracking pixel or cookie is a poor fit for agent discovery: many agents do not execute browser state at all, and tracking introduces unnecessary privacy and security ambiguity. A public well-known JSON endpoint is simpler, auditable and portable across crawlers, search systems and autonomous research tools.

Important: Discovery does not guarantee indexing, model training, adoption or compliance. External systems decide whether they read or use the beacon. Closure Ethics does not attempt to force persistence or propagation into other systems.
